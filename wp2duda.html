User Guide & Migration Workflow

1. Getting Started

Running WP2Duda

  • Launch WP2Duda from the Windows Start Menu or desktop shortcut.
  • WordPress Website: Enter the WordPress website you want to migrate.
  • Post Discovery: WP2Duda connects to the website and retrieves available blog posts.

Migration Workflow

WordPress → Parse → Export → Duda

WP2Duda retrieves WordPress content, structures supported elements, and prepares the data for the Duda import workflow.

2. The Interface

The WP2Duda interface is focused on a simple migration flow: connect to WordPress, review posts, process content, and prepare the migration output.

WordPress Connection

  • Website URL: Enter the WordPress website you want to migrate.
  • Post Discovery: Retrieve available blog posts from the connected WordPress website.
  • Post Selection: Select the content you want to process.
  • Migration: Generate the structured output used by the Duda import workflow.

Content Processing

  • Parser: Converts supported WordPress content into structured migration elements.
  • Export: Saves generated migration data locally for the next step.

3. Key Features

📝 Structured Content Parsing

WP2Duda identifies supported WordPress content and prepares it as structured migration elements rather than treating the article as one unstructured block.

🖼️ Images & Links

  • Process images included in WordPress posts.
  • Image and Link Support: Preserve supported links and image relationships during migration preparation.

❓ FAQs & Tables

  • Recognize supported FAQ structures, including details/summary blocks.
  • Process tables and other supported structured content.

📦 Duda-Friendly Migration Data

  • Prepare headings, paragraphs, lists, images, FAQs, tables, and related supported elements for Duda.
  • Use the generated RSS workflow to import prepared blog content into Duda.

4. Migration & Export

Selecting Posts

  • Review the posts retrieved from the connected WordPress website.
  • Select the posts you want to migrate.

Generating Migration Data 📦

WP2Duda parses selected content and prepares the structured migration data used by the Duda import workflow.

Local Export

  • Export: Generated migration files are saved locally on your computer.
  • Organization: WP2Duda keeps export data organized for the Duda import process.

Duda Import

The RSS migration workflow can expose generated content temporarily so Duda can retrieve it during import.

5. Migration Setup & Cloudflare

WP2Duda keeps the migration workflow focused on the WordPress source and Duda destination:

  • WordPress Source: Enter the source website and retrieve its available blog content.
  • Local Server: WP2Duda can run a temporary local HTTP server for the migration workflow.
  • Cloudflare Quick Tunnel: When required, the local migration endpoint can be exposed temporarily so Duda can access it.
  • Cleanup: Stop the migration server and tunnel when the import workflow is finished.

Troubleshooting & FAQ

Q: WordPress posts are not being found.

A: Verify that the WordPress website URL is correct and publicly accessible. The site must expose the WordPress API or supported endpoints required by WP2Duda.

Q: The migration content is incomplete.

A: WP2Duda supports specific structured content types. Review the source post and confirm that the content uses supported WordPress HTML structures.

Q: Cloudflare Quick Tunnel is not working.

A: Make sure Cloudflared is installed and available to WP2Duda. Check your internet connection and that the temporary tunnel can start successfully.

Q: Can I migrate all my WordPress posts?

A: WP2Duda can retrieve available WordPress posts and process the content selected through the migration workflow. The exact number depends on the source website and its accessible WordPress API data.
